# M8 Release packaging

Issue [#20](https://github.com/reteter/vidsc/issues/20) preserves the existing staged,
framework-dependent win-x64 expanded bundle and promotion rollback transaction.
This increment adds exact CLI/native hash enforcement, a pre-customization complete
scene-runtime input digest, an allowlisted scene manifest without build-machine paths,
bundled usage/distribution notices and a complete final package inventory.

The source runtime digest excludes interpreter-generated bytecode. Packaging discards
all incoming `.pyc`/`__pycache__`, disables new bytecode through `sitecustomize`, and
generates only that trusted module's checked-hash cache with a neutral embedded source
filename. The final package inventory includes all shipped bytes, including that cache.
It rejects hidden/unlisted/tampered files, noncanonical/duplicate paths, reparse points,
bundled .NET runtimes and host-dependent `pyvenv.cfg`.

## Preliminary evidence

The existing SDK selected 10.0.201 and Windows Desktop Runtime 10.0.5 on Windows 11
build 26200. A preliminary `Build-Release.ps1 -SkipSmokeTest` passed native/CLI identities,
packaged probe/copy/color oracles, full/windowed/adaptive scenes, inventory and promotion.
No GUI was launched. This package preceded final integration and subsequent bytecode
hardening; it is not the final acceptance artifact.

The first delivery driver compiled successfully but runtime resolution failed before
its entry point because the wrapper's `Private=false` references omitted dependencies
from its runtime metadata. Restoring normal SDK reference copying fixes that harness
contract. The next driver reached real native qualification and correctly refused the
stereo AAC fixture as `UnsupportedAudioRepresentation`. The existing qualified policy
requires 48-kHz 5.1 AAC. The fixture and preflight now explicitly require that layout;
no product audio policy was broadened.

Focused inventory controls pass intact files, changed bytes, unlisted files, hidden
injection, inventoried hidden files and forbidden hidden framework-runtime files.
PowerShell parsing and `git diff --check` pass. The final integrated build and single
fresh-location delivery run are recorded separately after freezing the code.

## Scope and distribution

The non-GUI driver uses actual metadata/scene/copy/accurate/project-store adapters;
it does not establish the window/open/play/presented-frame/GUI shutdown gates or full
deferred M1 acceptance. It saves/reloads an actual project document but does not claim
a complete interactive editor trial. A clean PATH and fresh work/temp/extraction
directory establish runtime lookup independence, not a cold OS cache or missing-runtime
host certification. No older Windows minimum has been certified.

The bundle remains private-local-only with `redistributionEligible: false`. Playback
native FFmpeg actually reports GPLv3-or-later, distinct from managed Flyleaf's LGPL.
CLI GPL and the PyAV wheel's separate native dependency provenance require the exact
source/build/replacement materials described in [distribution obligations](../distribution.md).
Wheel-byte research compared all eight pinned wheel archives with the installed tree:
all archive hashes and 1,371 payload files match; eight installer-rewritten `RECORD`
files are excluded from that payload comparison and remain bound by the input-tree digest.
This evidence does not clear public binary redistribution.
