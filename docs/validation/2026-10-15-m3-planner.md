# Draft whole-range copy planner

Execution: [#32](https://github.com/reteter/vidsc/issues/32), parent
[#13](https://github.com/reteter/vidsc/issues/13). The separate finite remux proof is
[PR #35](https://github.com/reteter/vidsc/pull/35); this increment starts from the
default branch and does not depend on its implementation files.

`CopyBoundaryPlanner` selects one indivisible supplied range and retains its
source/generation/stream/time-base/configuration binding, packet manifest identity
and packet ordinals. It never combines a start from one observation with an end
from another. Observations and returned proposals are transparent draft data;
they do not establish dependency safety or authorize export/promotion.

Expand requires a containing interval; contract requires a contained interval.
Nearest minimizes the sum of absolute endpoint deviations. Equal distances favor
expansion, then earlier start, later end, ordinal observation/manifest identity and
packet ordinals. Selection is deterministic even with duplicate observation IDs.

Exact rational comparisons accept mixed request bases without rounding. Candidate
bases must match their bound source; stale candidates are skipped without poisoning
current candidates. Empty requests/ranges and missing identities yield no proposal.
Unrepresentable exact times/ranking distances throw the documented overflow error.

The proposal preserves original numeric and frame-resolved requests. `CopySnap*`
deltas measure the additional copy-boundary shift; `Total*` deltas measure the full
shift from original numeric requests. The proposed output epoch is the selected start.

Focused tests cover all policies, mixed-direction nearest, deterministic ties,
each stale binding dimension, exact sub-tick comparisons, both delta stages,
empty/missing candidates, invalid streams and the explicit arithmetic limit.
Required local CI passes Release restore/build, PowerShell parsing, four rollback
scenarios and 348 unit cases. Focused independent review found and verified fixes
for incomplete tie-breaking and ambiguous delta naming.

Remaining #32 integration must supply actually verified finite-range evidence and
keep execution eligibility in the media layer. This API alone completes neither
#32 nor M3. No media runtime tests, M1 acceptance or #28 work are part of this increment.
