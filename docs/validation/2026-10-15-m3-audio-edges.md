## Independent fixture and checks

The new script authors four seconds of 48 kHz, six-channel float PCM. Each channel
has a symmetric 10 ms triangular pulse with amplitude 0.7 at independently fixed
sample centers. For channel `c` (0–5), centers in seconds are:

- source start: `0.015 + 0.003*c`;
- first cut edge: `1.015 + 0.003*c`;
- last cut edge: `1.965 + 0.003*c`.

AAC at 384 kbit/s and AC-3 at 448 kbit/s are encoded from that PCM alongside the
existing synthetic AVC fixture. This cell has no delayed-track offset; the earlier
delayed AAC/AC-3 cell remains separate evidence. Only the generated fixture is
encoded; candidate outputs copy compressed packets without conversion.

The source decoder establishes the reference independently of each copied output.
Source pulse timing must be within the existing 12 ms authored-center tolerance,
with peak amplitude above 0.05. Relative source/output timing must agree within one
48 kHz sample. Exact rational packet times, payload hashes and configuration are
checked separately. Neither average FPS nor a measured output peak defines the
expected source center.

The first and last 50 ms each cover exactly 2400 samples per channel. Every source
and output grid coordinate must have one observation. Source self-mapping and a
one-sample-hole control qualify the grid harness. All channels have authored pulse
centers inside both windows. Exact PCM comparison is a diagnostic independent of
the timing policy; no PCM tolerance was chosen to make a candidate pass.

## Observed results

The interior `[1, 2)` case preserves selected packet payloads, representation and
exact common-epoch timing. All 24 channel/edge pulse comparisons pass the unchanged
relative timing policy. Both tracks have complete non-overlapping edge coverage.
The observed relative peak error is zero samples; selected interior packet counts
are 12 video, 48 AAC and 32 AC-3. The run generates approximately 5.27 MB in total.
AAC edge PCM is identical. AC-3 maximum absolute deviation is approximately
0.000181735 in normalized float samples; this is reported rather than accepted as
sample-exact audio or turned into a new error tolerance.

A real damaged remux removes the first selected packet from both audio tracks.
Its payload manifests must equal the selected manifests with precisely that packet
removed. It introduces 128 missing AAC samples and 896 missing AC-3 samples at the
first edge. Rejection requires this new loss against a complete baseline; existing
PCM differences cannot satisfy the control. Passing the intact baseline as a no-op
does not reject it.

The separate AAC source-start case copies observed startup packets, including a
negative packet, at epoch zero. Source and output both declare 1024 leading skip
samples. The first packet begins at `-1024/48000` seconds, fresh decode begins at
zero, and the measured leading discard is exactly 1024 samples. Payloads and packet
times are preserved; all six startup pulse mappings pass the unchanged timing
policy. This qualifies observed encoder/container skip behavior for this fixture.
It does not infer encoder priming from decoder delay or absent side data.

## Bounds, reproduction and claim limits

```powershell
artifacts/runtime/scene/python/python.exe tools/scene/test_m3_audio_edges.py --video artifacts/m3-copy/iteration-3/h264.mp4 --ffmpeg C:/ffmpeg/bin/ffmpeg.exe --work-dir artifacts/m3-tracks/audio-edges-new-run
```

Use a new owned work directory. Generated files and raw reports remain ignored.
The script imports the existing bounded helpers: 16 MiB aggregate generated bytes,
1024 packets per scan, 512 audio frames per decode, 30-second subprocess deadlines
and bounded native decode budgets. Reports are limited to 2 MiB; the input video
hash must remain unchanged. Runtime identities are recorded in the report/logs.
The measured stack is packaged Python 3.14.5/PyAV 19.0.1 with libavcodec 63.1.102,
and CLI FFmpeg `N-121120-gc74181a04b` for fixture encoding.

Two initial native attempts pass: the first established the new cases; the second
checked corrected fixture labels in damaged rows and explicit codec-wide claim
limits. This remains within the three-attempt budget. No guessed preroll or relaxed
timing threshold was introduced.

Focused static review found no remaining blocking oracle findings after the report
labels were corrected. Required local CI passes 384 cases, Release restore/build,
tracked PowerShell parsing and four promotion/rollback scenarios. This CI result
does not replace the native cases above.

This is a native PyAV proof, not production CLI multitrack eligibility, general
codec priming, sample-exact audio, arbitrary EOF or external-player acceptance.
AC-3 source-start priming, wider offset/timing cells, MKV/SubRip/chapters and the
remaining M3 gate stay open in #34. M1 remains deferred; #28 is excluded.
